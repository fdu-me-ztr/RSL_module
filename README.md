# Simple RSL 递归自我学习系统

作业二：使用本地 Ollama 构建一个回答、自我评审、递归修订及经验记忆系统。

## 项目范围

RSL 在本项目中指 Recursive Self-Learning。此处实现的是基于反馈和持久化经验的轻量原型，不是训练新模型，不修改 Qwen 的参数，也不是完整科研算法复现。模型评审通过不等于事实已经正确。

课程提供的参考为 https://github.com/NewYearEve-Godsheep/ModelRouterCourse 。它侧重模型路由。本项目根据作业中 RSL 的定义独立编写，未复制该仓库代码，不声称实现其完整路由功能。

## 运行要求

- Python 3.10 或以上；仅使用标准库，不需要 pip 安装依赖。
- 安装并启动 Ollama，默认地址 http://127.0.0.1:11434 。
- 下载模型：`ollama pull qwen2.5:3b`。
- 实验环境：Windows、RTX 5060 Laptop GPU（8 GB）、16 GB 系统内存。

## 快速开始

在本文件所在文件夹打开 PowerShell：

```powershell
python rsl.py "使用辗转相除法计算48和18的最大公约数，列出步骤。"
```

终端打印最终答案、终止原因、评审轮数及使用经验数量。`data/latest.json` 保存每轮完整答案和评审，`data/memory.json` 保存符合条件的经验。再次问相关问题可以验证记忆检索：

```powershell
python rsl.py "使用辗转相除法计算84和30的最大公约数，列出步骤。" --output data/second.json
```

学习效果不能仅靠记忆条数证明，需要对比实际答案正确性。

## 工作流程

```text
问题 → 检索相关历史经验 → 生成初始答案 → 自我评审
                                          ├─ 通过 → 输出并保存经验
                                          └─ 未通过 → 修订 → 递归评审
```

1. 使用英文词及中文二字片段的 Jaccard 相似度检索最多三条经验（非向量数据库）。
2. 用同一个 Qwen 分别承担回答者、评审者、修订者角色。
3. 评审输出结构化 JSON：score、passed、issues、lesson。
4. 分数达到阈值、passed=true 且 issues 为空时结束；只有此时保存非空经验。
5. 默认最多三轮，最高允许五轮；达到轮数、评审格式非法或修订无变化时停止，不保存经验。
6. 记忆最多保留最近100条，完全重复的经验不重复写入。

参数说明：

| 参数 | 默认值 | 作用 |
|---|---|---|
| --model | qwen2.5:3b | Ollama模型名称 |
| --rounds | 3 | 最大评审轮数，1到5 |
| --threshold | 8 | 接受分数阈值，0到10 |
| --no-memory | 关闭 | 加上此开关则不读写记忆 |
| --memory | data/memory.json | 经验库路径 |
| --output | data/latest.json | 完整运行记录路径 |

终止状态：self_review_passed（自评通过）、max_rounds（达到轮数上限）、no_change（修订无变化）、invalid_review（评审格式不合格）。最后三个状态不代表答案合格。

## 验证与实验

```powershell
python -m unittest discover -s tests -v
```

六项自动测试覆盖递归改错、轮数上限、非法评审、停止重复、相关记忆检索以及非法分数。测试用可控的模拟模型验证控制逻辑，不将模拟输出作为真实模型能力结果。

`examples/real_run.json` 为本机真实 Ollama 调用记录；测试问题的标准答案是6，但模型错误输出12且自评通过。这是保留的失败案例，展示自我评审的局限，不是正确性通过记录。

推荐作业展示：

1. 对48与18求GCD，保存输出截图和JSON，人工核对余数12、6、0。
2. 对同步复位与异步复位提问，观察评审是否提出有效问题。
3. 对同类问题分别开启和关闭记忆，记录答案、使用经验数量、轮数与人工判断。
4. 如首轮直接通过，如实记录，不为展示“进步”捏造多轮修改。

## 局限与改进

同一模型可能重复自己的错误，自己给出的分数也未校准。经验可能包含错误，后续应加入人工审核、独立评审模型和领域验证器。规则检索可能漏掉语义相关问题；以后可接入向量检索。本地记忆是明文文件，勿输入密码或私人资料。本工具面向单用户命令行实验，不支持并发写入同一经验库。

## 故障排查

- 无法调用Ollama：启动Ollama应用，执行 `ollama list` 确认模型已下载。
- 评审格式错误：系统会安全停止；查看完整JSON记录后重新运行。
- 没有使用记忆：首次运行或没有相似问题时是正常现象；经验仅在自评通过后写入。
- 运行较慢：每轮包含模型调用，最多五轮；可以先设置 `--rounds 2`。
